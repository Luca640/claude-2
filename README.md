# claude-2

Automated YouTube Shorts studio: original 3D cartoon story shorts rendered with three.js + Remotion.

- `CONTENT_BRIEF.md` — the creative brief and production instructions for the channel.
- `skills/cartoon-3d-short/` — the production skill, copied unchanged from
  [mromidev/claude-animated-shorts](https://github.com/mromidev/claude-animated-shorts) (MIT, see its `LICENSE`).
  Story, characters, voice and assets for new videos must always be original; the reference frames are for style study only.
